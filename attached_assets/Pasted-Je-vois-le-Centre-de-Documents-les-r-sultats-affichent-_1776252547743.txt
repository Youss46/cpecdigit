> ### 5. Ajouter le bouton Imprimer sur tous les documents
>
> ```jsx
> // Composant document avec PDF + Impression
> const DocumentItem = ({ titre, semestre, classeId, semestreId, type }) => {
>
>   // Télécharger PDF
>   const telecharger = async () => {
>     const blob = await api.get(
>       `/documents/${type}/pdf?classe_id=${classeId}&semestre_id=${semestreId}`,
>       { responseType: 'blob' }
>     );
>     const url = URL.createObjectURL(blob);
>     const a = document.createElement('a');
>     a.href = url;
>     a.download = `${titre}_${semestre}.pdf`;
>     a.click();
>   };
>
>   // Imprimer directement
>   const imprimer = async () => {
>     const blob = await api.get(
>       `/documents/${type}/pdf?classe_id=${classeId}&semestre_id=${semestreId}`,
>       { responseType: 'blob' }
>     );
>     const url = URL.createObjectURL(blob);
>
>     // Ouvrir dans un iframe caché et lancer l'impression
>     const iframe = document.createElement('iframe');
>     iframe.style.display = 'none';
>     iframe.src = url;
>     document.body.appendChild(iframe);
>     iframe.onload = () => {
>       iframe.contentWindow.print();
>       // Nettoyer après impression
>       setTimeout(() => {
>         document.body.removeChild(iframe);
>         URL.revokeObjectURL(url);
>       }, 5000);
>     };
>   };
>
>   return (
>     <div className="document-item">
>       <div className="document-info">
>         <p className="document-titre">{titre}</p>
>         <p className="document-semestre">{semestre}</p>
>       </div>
>       <div className="document-actions">
>         <button onClick={telecharger} className="btn-pdf">
>           📥 PDF
>         </button>
>         <button onClick={imprimer} className="btn-imprimer">
>           🖨️ Imprimer
>         </button>
>       </div>
>     </div>
>   );
> };
> ```

Le point critique est la **jointure `semestres.classe_id`** — sans cette liaison en base, le système ne peut pas savoir quels semestres appartiennent à quelle classe et affiche tous les semestres pour toutes les classes. Une fois la liaison correctement établie, tous les filtres du Centre de Documents se corrigent automatiquement.
