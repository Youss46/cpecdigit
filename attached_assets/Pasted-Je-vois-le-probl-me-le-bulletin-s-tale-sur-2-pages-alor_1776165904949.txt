Je vois le problème : le bulletin s'étale sur **2 pages** alors qu'il devrait tenir sur **1 seule page** comme un bulletin physique. Voici le prompt :

---

**Prompt :**

---

> Dans **CPEC-Digital**, dans le module **Bulletins de Notes**, optimiser la génération PDF pour que le bulletin tienne sur **une seule page A4**, comme un bulletin physique traditionnel.
>
> ---
>
> ### 1. Problème identifié
> - Le bulletin généré s'étale sur **2 pages** (1/2 visible en haut de capture)
> - La page 1 contient les notes, la page 2 contient le récapitulatif et les signatures
> - Un bulletin physique tient toujours sur **1 feuille recto** ou **recto-verso**
>
> ---
>
> ### 2. Stratégie de compression sur une page
>
> Plusieurs ajustements combinés permettent de tout faire tenir :
>
> ```javascript
> // Paramètres PDF optimisés pour tenir sur 1 page A4
> const options = {
>   format: 'A4',
>   orientation: 'portrait',
>   margin: {
>     top: '8mm',      // ← Réduire (était probablement 15-20mm)
>     bottom: '8mm',   // ← Réduire
>     left: '10mm',    // ← Réduire
>     right: '10mm'    // ← Réduire
>   }
> };
> ```
>
> ---
>
> ### 3. Réduction des espacements CSS
>
> ```css
> /* Bulletin PDF — Version compacte une page */
>
> /* En-tête plus compact */
> .bulletin-header {
>   padding: 6px 10px;        /* Réduire padding */
>   font-size: 9px;           /* Réduire police en-tête */
> }
>
> /* Infos étudiant plus denses */
> .etudiant-info {
>   font-size: 8.5px;
>   line-height: 1.3;
>   margin-bottom: 4px;       /* Réduire espacement */
> }
>
> /* Titres UE plus petits */
> .ue-titre {
>   font-size: 8px;
>   padding: 2px 6px;
>   margin-top: 4px;
>   margin-bottom: 2px;
> }
>
> /* Tableau des matières compact */
> .table-matieres td,
> .table-matieres th {
>   font-size: 8px;
>   padding: 2px 6px;         /* Réduire padding cellules */
>   line-height: 1.2;
> }
>
> /* Récapitulatif compact */
> .recapitulatif {
>   font-size: 8.5px;
>   padding: 4px 8px;
>   margin-top: 4px;
> }
>
> /* Signatures compactes */
> .signatures {
>   margin-top: 6px;
>   font-size: 8px;
> }
>
> /* Pied de page compact */
> .footer-bulletin {
>   font-size: 7px;
>   margin-top: 4px;
> }
> ```
>
> ---
>

>
> ### 5. Ajustement dynamique selon le nombre de matières
>
> ```javascript
> // Calculer dynamiquement la taille de police selon le nombre de matières
> const calculerTaillePolice = (nbMatieres) => {
>   if (nbMatieres <= 8)  return { corps: 9,   ue: 8.5, cellule: 8   };
>   if (nbMatieres <= 12) return { corps: 8.5, ue: 8,   cellule: 7.5 };
>   if (nbMatieres <= 16) return { corps: 8,   ue: 7.5, cellule: 7   };
>   return                       { corps: 7.5, ue: 7,   cellule: 6.5 };
>   // En dernier recours : passer en A4 paysage
> };
>
> const tailles = calculerTaillePolice(matieres.length);
> ```
>
> ---
>
> ### 6. Option recto-verso si trop de matières
>
> Si l'étudiant a **plus de 16 matières** et que tout ne peut pas tenir sur une page :
>
> ```javascript
> const choisirFormat = (nbMatieres) => {
>   if (nbMatieres <= 14) return 'UNE_PAGE';      // Portrait compact
>   if (nbMatieres <= 20) return 'RECTO_VERSO';   // 2 pages liées
>   return 'PAYSAGE';                             // A4 paysage
> };
> ```
>
> ---
>
> ### 7. Supprimer les espaces vides inutiles
>
> Sur la capture, plusieurs éléments gaspillent de l'espace :
>
> | Élément | Correction |
> |---|---|
> | Espacement entre UEs trop grand | Réduire `margin-bottom` des blocs UE à **3px** |
> | Titre "UE DE CULTURE GÉNÉRALE" prend trop de place | Intégrer dans la ligne UE1 directement |
> | Lignes vides entre tableaux | Supprimer tous les `<br>` et spacers inutiles |
> | Padding excessif dans les cellules | Réduire à `2px 6px` |

---

La clé est l'**ajustement dynamique de la taille de police** selon le nombre de matières — un bulletin avec 6 matières peut utiliser une police de 9px, tandis qu'un avec 14 matières descendra à 7px pour tout faire tenir. C'est exactement ce que font les bulletins physiques imprimés.
