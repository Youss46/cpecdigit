> ### Problème 1 — Séparateur "/" toujours présent dans les montants
>
> **Constat :** Les montants affichent toujours **200/000 FCFA**, **150/000 FCFA**, **50/000 FCFA**, **100/000 F(** — le séparateur `/` n'a pas été corrigé
>
> **Correction :**
> ```javascript
> // ✅ Appliquer sur TOUS les montants du PDF
> const formaterMontant = (montant) => {
>   if (!montant && montant !== 0) return '—';
>   return new Intl.NumberFormat('fr-FR', {
>     minimumFractionDigits: 0,
>     maximumFractionDigits: 0
>   }).format(montant) + ' FCFA';
> };
>
> // Résultat attendu :
> // 200 000 FCFA ✅
> // 150 000 FCFA ✅
> //  50 000 FCFA ✅
> // 100 000 FCFA ✅
> ```
>
> > ⚠️ Vérifier que cette fonction est bien **appelée partout** dans le générateur PDF — récapitulatif financier ET historique des paiements
