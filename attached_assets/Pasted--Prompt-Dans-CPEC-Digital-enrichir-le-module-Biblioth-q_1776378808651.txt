> ### 2. Quiz interactifs associés aux cours
>
> #### Création du quiz par l'enseignant
>
> Après avoir uploadé un support, l'enseignant peut créer un quiz associé :
>
> ```
> ➕ Ajouter un quiz à ce support
> ─────────────────────────────────────────────
> Titre du quiz : "Quiz Chapitre 1 — Droit social"
> Durée limite  : 15 minutes (optionnel)
> Note minimale : 10/20 (optionnel)
> Tentatives    : 2 (nombre de passages autorisés)
>
> Questions :
> ┌─────────────────────────────────────────────┐
> │ Question 1 / 5                              │
> │                                             │
> │ Quelle est la durée légale du travail       │
> │ hebdomadaire en Côte d'Ivoire ?             │
> │                                             │
> │ ○ 35 heures                                 │
> │ ● 40 heures  ← Bonne réponse               │
> │ ○ 45 heures                                 │
> │ ○ 48 heures                                 │
> │                                             │
> │ Explication : Le Code du travail ivoirien   │
> │ fixe la durée à 40h par semaine...          │
> └─────────────────────────────────────────────┘
> [+ Ajouter une question]
> ```
>
> #### Types de questions supportés
>
> | Type | Description |
> |---|---|
> | **QCM** | 1 bonne réponse parmi 4 |
> | **QCM multiple** | Plusieurs bonnes réponses possibles |
> | **Vrai / Faux** | Réponse binaire |
> | **Texte libre** | Réponse courte corrigée manuellement |
> | **Mise en ordre** | Classer des éléments dans le bon ordre |
>
> #### Structure en base
> ```sql
> CREATE TABLE quiz (
>   id SERIAL PRIMARY KEY,
>   support_id INTEGER REFERENCES bibliotheque(id),
>   titre VARCHAR(200),
>   duree_minutes INTEGER,
>   note_minimale DECIMAL(4,2),
>   nb_tentatives INTEGER DEFAULT 1,
>   actif BOOLEAN DEFAULT true,
>   cree_par INTEGER REFERENCES users(id),
>   cree_le TIMESTAMP DEFAULT NOW()
> );
>
> CREATE TABLE quiz_questions (
>   id SERIAL PRIMARY KEY,
>   quiz_id INTEGER REFERENCES quiz(id),
>   texte TEXT NOT NULL,
>   type VARCHAR(20), -- 'qcm', 'vrai_faux', 'libre', 'ordre'
>   explication TEXT, -- Explication après réponse
>   points INTEGER DEFAULT 1,
>   ordre INTEGER
> );
>
> CREATE TABLE quiz_reponses (
>   id SERIAL PRIMARY KEY,
>   question_id INTEGER REFERENCES quiz_questions(id),
>   texte VARCHAR(500),
>   est_correcte BOOLEAN DEFAULT false,
>   ordre INTEGER
> );
>
> CREATE TABLE quiz_resultats (
>   id SERIAL PRIMARY KEY,
>   quiz_id INTEGER REFERENCES quiz(id),
>   etudiant_id INTEGER REFERENCES students(id),
>   score DECIMAL(4,2),
>   duree_secondes INTEGER,
>   tentative INTEGER DEFAULT 1,
>   termine_le TIMESTAMP DEFAULT NOW()
> );
> ```

> ### 4. Suivi du temps passé sur chaque support
>
> #### Tracking automatique
>
> ```javascript
> // Démarrer le chronomètre à l'ouverture d'un support
> const trackerTemps = {
>   debut: null,
>   supportId: null,
>
>   demarrer: (supportId) => {
>     trackerTemps.debut = Date.now();
>     trackerTemps.supportId = supportId;
>
>     // Enregistrer si l'étudiant quitte la page
>     window.addEventListener('beforeunload', trackerTemps.enregistrer);
>     document.addEventListener('visibilitychange', () => {
>       if (document.hidden) trackerTemps.enregistrer();
>       else trackerTemps.debut = Date.now(); // Reprendre au retour
>     });
>   },
>
>   enregistrer: async () => {
>     if (!trackerTemps.debut) return;
>     const dureeSecondes = Math.floor(
>       (Date.now() - trackerTemps.debut) / 1000
>     );
>     if (dureeSecondes < 5) return; // Ignorer les passages rapides
>
>     await api.post('/bibliotheque/tracker', {
>       support_id: trackerTemps.supportId,
>       duree_secondes: dureeSecondes
>     });
>     trackerTemps.debut = null;
>   }
> };
> ```
>

> ### 5. Recommandations de révision avant les examens
>
> #### Déclenchement automatique
>
> Le système génère des recommandations **15 jours avant chaque examen** :
>
> ```javascript
> const genererRecommandations = async (etudiantId, semestreId) => {
>   const examens = await getExamensProchains(semestreId, 15); // 15 jours
>
>   for (const examen of examens) {
>     const analyse = await analyserEtudiant(etudiantId, examen.matiere_id);
>
>     // Calculer le score de priorité
>     const priorite = calculerPriorite({
>       noteActuelle: analyse.moyenne,          // Note actuelle
>       tempsConsulte: analyse.temps_total,     // Temps sur les supports
>       scoreQuiz: analyse.score_moyen_quiz,    // Score aux quiz
>       joursAvantExamen: examen.jours_restants // Urgence temporelle
>     });
>
>     await sauvegarderRecommandation({
>       etudiant_id: etudiantId,
>       matiere_id: examen.matiere_id,
>       priorite,                    // haute / moyenne / faible
>       supports_recommandes: analyse.supports_non_consultes,
>       quiz_recommandes: analyse.quiz_echoues
>     });
>   }
> };
> ```
>

>
> ### 7. Statistiques pour l'administration
>
> | Indicateur | Détail |
> |---|---|
> | Support le plus consulté | Par matière et semestre |
> | Temps moyen par étudiant | Par matière |
> | Score moyen aux quiz | Par matière et par classe |
> | Corrélation temps/résultat | Les étudiants qui révisent plus ont-ils de meilleurs résultats ? |
> | Étudiants jamais connectés | Liste pour intervention ciblée |

---

La fonctionnalité la plus impactante est la **corrélation temps de révision / résultats aux examens** — c'est une donnée que les établissements n'ont jamais pu mesurer auparavant et qui permettrait de prouver scientifiquement l'utilité de la bibliothèque numérique, renforçant considérablement l'argument commercial de CPEC-Digital.
