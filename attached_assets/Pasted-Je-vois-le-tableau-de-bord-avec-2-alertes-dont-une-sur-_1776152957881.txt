> ### 2. Décrémenter le compteur d'alertes après résolution
>
> **Constat :** Quand on clique sur une alerte et qu'on résout une situation, le **badge numérique** et le **compteur** ne se mettent pas à jour — ils affichent toujours l'ancien nombre.
>
> **Correction — Mise à jour en temps réel après action :**
>
> ```javascript
> // Principe : après toute action de résolution → refetch immédiat
>
> // Exemple 1 — Valider les notes d'une matière
> const validerNotes = async (matiereId) => {
>   await api.post(`/notes/${matiereId}/valider`);
>
>   // Refetch immédiat du résumé des alertes
>   await queryClient.invalidateQueries(['alertes-dashboard']);
>   // → Le compteur passe de 5 à 4 automatiquement
> };
>
> // Exemple 2 — Traiter une réclamation
> const traiterReclamation = async (reclamationId, decision) => {
>   await api.post(`/reclamations/${reclamationId}/decider`, { decision });
>
>   // Refetch immédiat
>   await queryClient.invalidateQueries(['alertes-dashboard']);
>   // → Le compteur passe de 2 à 1 automatiquement
> };
>
> // Exemple 3 — Marquer un message comme lu
> const marquerLu = async (messageId) => {
>   await api.patch(`/messages/${messageId}/lu`);
>
>   // Refetch immédiat
>   await queryClient.invalidateQueries(['alertes-dashboard']);
> };
> ```
>

> ### 3. Logique de calcul du badge principal
>
> ```javascript
> // Le badge "X alertes en attente" = somme de toutes les alertes actives
> const calculerTotalAlertes = (alertes) => {
>   return alertes
>     .filter(a => a.count > 0)       // Ignorer les alertes à 0
>     .reduce((sum, a) => sum + a.count, 0);
> };
>
> // Exemples :
> // notes=5, absences=3, reclamations=2 → badge affiche "10"
> // Après résolution 1 note → notes=4 → badge affiche "9"
> // Après résolution toutes → badge disparaît complètement
>
> {totalAlertes > 0 && (
>   <span className="badge-alerte">{totalAlertes}</span>
> )}
> // Si totalAlertes = 0 → badge invisible
> ```
>

>
> ### 4. Animation de décrémentation
>
> ```jsx
> // Afficher une animation quand le compteur diminue
> const BadgeAlerte = ({ count }) => {
>   const [prevCount, setPrevCount] = useState(count);
>   const [animate, setAnimate] = useState(false);
>
>   useEffect(() => {
>     if (count < prevCount) {
>       setAnimate(true); // Déclencher animation ↓
>       setTimeout(() => setAnimate(false), 500);
>     }
>     setPrevCount(count);
>   }, [count]);
>
>   return (
>     <span className={`badge ${animate ? 'badge-decrement' : ''}`}>
>       {count}
>     </span>
>   );
> };
> ```
